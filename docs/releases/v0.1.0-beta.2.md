# Space Maid 0.1.0-beta.2

- Setup now detects an existing per-user installation and offers **Update Space Maid**. It applies the embedded update package through the installed updater, keeping settings and photo catalogs beside the app.
- Running Setup when the same or a newer version is installed offers **Open Space Maid**. Fresh installations require an empty destination; portable mode still uses a separate empty folder.

This release contains the installer fix on top of beta.1. For existing installations, use this Setup or the in-app updater instead of the overwrite option in older Setup releases.

Windows x64 beta. Binaries are unsigned. Original-photo cleanup remains disabled.
