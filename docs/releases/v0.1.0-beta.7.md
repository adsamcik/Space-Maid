# Space Maid 0.1.0-beta.7

- In Explore, press **Delete** in the tree or choose **Move to Recycle Bin** to recycle a file or folder in one step. You can restore it from the Recycle Bin.
- If Windows cannot recycle the item, Space Maid shows its exact path and asks before deleting it permanently. **Shift+Delete** and **Delete permanently…** open the same warning.
- Explore keeps the removal result visible even if some scan data could not refresh.

Windows x64 beta. Binaries are unsigned.
