# Space Maid 0.1.0-beta.6

- Explore now crosses out a folder as soon as Windows verifies that it moved to the Recycle Bin. The row stays marked while Explore still shows the earlier scan.
- Folder recycling opens confirmation using the existing scan estimate, without rescanning the folder first. You can keep browsing Explore while Windows moves the folder and Space Maid refreshes the results.

Windows x64 beta. Binaries are unsigned.
