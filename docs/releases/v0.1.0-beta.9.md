# Space Maid 0.1.0-beta.9

- Explore opens ready to scan. Enable the optional fast scanner from **More**. File and folder deletions show immediate feedback and run in a queue so you can keep browsing. Recycle Bin refusals stay available for review before you decide whether to delete an item permanently.
- Cleanup shows estimates and the next action up front. Expand **More cleanup options** to adjust build retention or removal policy. Optimize Space shows permanent deletion after a file review and puts automatic cleanup limits in a separate disclosure.
- Duplicate search and cloud-drive discovery start when opened. Photos finds files again after you move a collection, and **Find suggestions** refreshes the local assistant's evidence when needed.
- Scans, cleanup reviews, and tool inspections retain more context after interruptions. Photos can resume analysis, cloud listings can continue in pages, and unreadable saved data gets a recovery path.

Windows x64 beta. Binaries are unsigned.
