# AI and agent storage

The bundled Developer module detects agent history, file checkpoints and model downloads in Opportunities. Tool breakdowns use the completed scan's metadata only: no transcript/database/model content reads, tool execution, environment-variable reads or extra disk traversal. This is a practical selection of widely used tools, not a measured popularity ranking.

All AI findings require review. Complete Hugging Face and LM Studio repositories can use the in-app Recycle Bin review. The shared Ollama library and application stores that contain credentials remain **kept**, including through selected ancestors; individual Ollama models use the **AI models** workflow. Restrictions are rediscovered during preparation and execution. An observed size is not guaranteed recovery. Nested findings count once within a group; groups can overlap.

The top **Detected storage** total includes kept stores. Only eligible cleanup checkboxes are enabled. See [in-app cleanup and confirmation](containers-and-wsl.md) for model, Docker and disk actions.

## Coverage and evidence

Paths below are relative to the user profile unless shown otherwise. Evidence checked on 2026-10-25; tools can change their layouts.

Each worktree can bring another dependency tree and build cache. Keep useful history; worktree cleanup retains Space Maid's Git status, activity and integration checks. [Official worktree documentation](https://learn.chatgpt.com/docs/environments/git-worktrees). |

Global storage includes extensions and potentially credentials. Manage chats in Cursor. | Gemini CLI | `.gemini/tmp/<project>/chats` with `session-*.json` | The `tmp` path contains resumable conversations. Review with `gemini --list-sessions` and Gemini's retention/deletion controls. [Session management](https://geminicli.com/docs/cli/session-management/). |
| Cline / Roo Code | `globalStorage/saoudrizwan.claude-dev/tasks/<task>` or `globalStorage/rooveterinaryinc.roo-cline/tasks/<task>` with conversation/UI-message files; Cline's sibling `checkpoints` | Task history and shadow Git snapshots can preserve unique work. Review tasks in the extension; checkpoint size does not establish waste. Existing Node/Python dependency, uv/pip/npm cache, build-output and Playwright browser/report detectors also cover common agent-driven installs, builds and browser testing. Worktree containers are never treated as disposable merely because of their name or age.

## Limits

Detection is scoped to the selected scan and visible metadata. Conventional agent paths require their owning ancestors in the inventory. Relocated Hugging Face and Ollama stores have recognizable layouts; arbitrary custom agent homes, editor profiles and LM Studio roots are not inferred from environment or configuration. [Containers and WSL coverage](containers-and-wsl.md) adds protected backing disks, local Docker inspection and cleanup guidance. RAG/vector databases, generic model files and incomplete model downloads have no new cleanup rule. Application processes, actual model use and download activity are not checked. Space Maid does not compact databases, execute suggested commands, change retention settings or remove real AI-tool data during detection or tests.

## Initial coverage verification

Release build passed with zero warnings on Windows/.NET 10. The suite and affected reruns together passed 426 distinct tests; three administrator-only checks were skipped. The final 37-test rerun included detection, grouping, extension loading and the complete WPF workflow. Preparation and execution tests preserve managed stores and selected ancestors even when restrictions appear after confirmation. Rendered light/dark 1220×910 and compact 1020×790 views were inspected using illustrative metadata, with model browsing and disabled cleanup controls exercised. An independent review's two presentation findings were addressed. These checks do not establish real-account integration or actual model/cache reclamation.
